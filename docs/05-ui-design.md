# 05 · UI 设计方案

## 1. 设计定位

**它不是仪表盘，是工作台。** 用户的真实动作是：读 200 步轨迹、比对 diff、录 90 秒视频、写 250 字反馈。
界面要像一张排布良好的工作台面：工具在手边，材料摊得开，当前在做什么一目了然。

三条设计原则：

1. **证据优先**：任何判断旁边都能看到支撑它的事实（SHA、行数、报错原文），不需要另开窗口找。
2. **状态不撒谎**：没有「大概完成了」。没做就是空白，做了才打勾，失败必须带一句人话。
3. **密度可调，默认偏密**：一屏 20 题必须能扫完，靠留白堆出来的「高级感」在这个场景是负资产。

反面清单（明确要避免的 AI 味）：紫蓝渐变、玻璃拟态、大圆角卡片墙、emoji 当图标、
每个区块都套阴影、居中大标题 + 副标题的落地页结构、无意义的微交互动画。

## 2. 视觉语言

### 2.1 隐喻

**台账 / 检定台**。参考对象是工程图纸、检验单、终端日志，而不是 SaaS 官网。

- 直角为主（圆角 2–4px，只有按钮和标签用 4px）
- 1px 实线分割，不用阴影分层（阴影只用于浮层）
- 数字与 ID 用等宽字体
- 状态用「点 + 文字」，不用大面积色块

### 2.2 色板

中性色偏暖（纸感），避免冷灰带来的「后台模板」观感。

```css
:root {
  /* 中性 */
  --paper:      #FBFAF8;   /* 页面底色 */
  --surface:    #FFFFFF;   /* 卡片/面板 */
  --surface-2:  #F5F3EF;   /* 表头、次级块、悬停 */
  --surface-3:  #ECE9E3;   /* 选中态底色 */
  --line:       #E2DED7;   /* 主分割线 */
  --line-soft:  #EFECE7;   /* 表格行内线 */
  --ink:        #1A1815;   /* 正文 */
  --ink-2:      #4C4842;   /* 次级正文 */
  --ink-3:      #857F76;   /* 说明、占位 */
  --ink-4:      #B4AEA4;   /* 禁用 */

  /* 强调：朱砂。只用于「当前/主操作」，全页面积 ≤ 3% */
  --accent:     #A83A22;
  --accent-ink: #8A2D19;
  --accent-bg:  #F7EAE5;

  /* 语义 */
  --ok:         #2F6B4F;   --ok-bg:    #E8F0EA;
  --warn:       #8A6416;   --warn-bg:  #F6EEDC;
  --danger:     #9B2C2C;   --danger-bg:#F8E7E7;
  --info:       #2C5C7C;   --info-bg:  #E6EEF3;
  --idle:       #857F76;   --idle-bg:  #F0EDE8;

  /* 尺寸 */
  --r-sm: 2px; --r-md: 4px; --r-lg: 6px;
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;
  --sp-5: 24px; --sp-6: 32px; --sp-7: 48px;
  --row: 44px;         /* 表格默认行高 */
  --row-dense: 36px;   /* 紧凑模式 */
  --label: 28px;       /* 表单标签宽 */
}
```

暗色模式不是反转，是**重新配一遍**（暖黑，不是蓝黑）：

```css
:root[data-theme="dark"] {
  --paper: #171614; --surface: #1E1C19; --surface-2: #24221E; --surface-3: #2C2924;
  --line: #34302A; --line-soft: #2A2722;
  --ink: #EDE9E2; --ink-2: #B9B3A9; --ink-3: #8B857B; --ink-4: #5E5850;
  --accent: #D4633F; --accent-ink: #E8825F; --accent-bg: #32211B;
  --ok: #6FAE8B; --ok-bg: #1D2A23;
  --warn: #C9A356; --warn-bg: #2B2418;
  --danger: #D97373; --danger-bg: #2E1D1D;
  --info: #7FA8C4; --info-bg: #1B252C;
}
```

### 2.3 字体

```css
--font-sans: "PingFang SC", "HarmonyOS Sans SC", -apple-system, "Segoe UI", sans-serif;
--font-mono: "JetBrains Mono", "SF Mono", "Menlo", monospace;
```

字号阶梯（只有 6 档，不允许临时造字号）：

| 用途 | 大小/行高 | 字重 |
|---|---|---|
| 页面标题 | 22/30 | 600 |
| 区块标题 | 17/24 | 600 |
| 正文/表格 | 13/20 | 400 |
| 次级说明 | 12/18 | 400 |
| 标签/徽标 | 11/16 | 500 |
| 数字与 ID | 12/18 | mono 400 |

**中文不加字间距**，英文标题可加 `0.01em`。数字表格一律 `font-variant-numeric: tabular-nums`。

### 2.4 图标与图形

- Lucide 线性图标，`stroke-width: 1.6`，尺寸只用 14/16/20。
- 状态统一用 6px 圆点 + 文字：`● 运行中`，颜色取语义色。不用彩色胶囊。
- 进度用 2px 细条或 1.5px 环形，不用粗进度条。

## 3. 基础组件（18 个）

| 组件 | 关键规格 |
|---|---|
| `Button` | 高 32（默认）/ 28（小）；主按钮实心 accent，次按钮描边，危险按钮描边 danger；禁用 `--ink-4` |
| `IconButton` | 28×28，悬停显示 `surface-2` 底 |
| `Input` | 高 32，1px `line` 边框，聚焦 `accent` 1px + 外 2px `accent-bg` |
| `Textarea` | 同上，`resize: vertical`，最小 3 行 |
| `Select` | 原生 `<select>` 定制外观，避免自定义下拉的键盘可达性问题 |
| `Checkbox` / `Radio` | 16×16，accent 选中 |
| `Switch` | 32×18 |
| `Tabs` | 下划线式，2px accent，高 36 |
| `Badge` | 高 20，`r-sm`，底色取语义 bg + 文字取语义色 |
| `StatusDot` | 6px 圆点 + label，`gap: 6px` |
| `Table` | 表头 sticky，行高 `--row`，斑马纹关闭，悬停 `surface-2`，单元格 `padding: 0 12px` |
| `StepRail` | 垂直 11 步，左侧 2px 连接线，当前步 accent 实心圆，完成步 ok 描边圆 |
| `SplitPane` | 可拖拽两栏，最小 240px，双击分隔条复位 |
| `Drawer` | 右侧滑出，宽 480/640，遮罩 `rgba(26,24,21,.32)` |
| `Modal` | 居中，宽 480，最大高 80vh，标题 + 正文 + 底部操作 |
| `Toast` | 右下，宽 320，最多 3 条，4s 消失，可手动关闭 |
| `Meter` | 细条仪表：`{value, max, thresholds:[{at,color}]}`，用于字数/锚点数 |
| `CodeBlock` | 等宽、行号可选、可复制、长行横向滚动、最大高 480 可折叠 |
| `EmptyState` | 图标 32 + 一句话 + 一个主操作，垂直居中，不写营销文案 |

**没有**：卡片网格、折叠面板、轮播、气泡引导、拖拽排序（除 SplitPane）。

## 4. 信息架构

```
/                       作业看板（默认）
/tasks                  任务列表（表格，可批量）
/tasks/:id              任务详情（三栏工作台）
/source                 题源：项目 → 工程 → 领取
/export                 导出与统计
/system                 设置：技能路径、题源地址、并发、凭据、日志
```

快捷键 `g d / g t / g s / g e / g system`（双击 g 前缀，300ms 窗口）。

## 5. 页面设计

### 5.1 全局框架

```
┌───────────────────────────────────────────────────────────────────────┐
│ ⌘K 搜索            ● 运行 3  ● 排队 2  ● 卡住 1      磁盘 128G   ◐   │ 48px 顶栏
├────┬──────────────────────────────────────────────────────────────────┤
│ ▤  │                                                                  │
│ ▦  │                        内容区                                     │
│ ⌸  │                                                                  │
│ ⧉  │                                                                  │
│ ⚙  │                                                                  │
└────┴──────────────────────────────────────────────────────────────────┘
 56px
```

顶栏常驻四件事：全局搜索入口、**运行/排队/卡住**三个实时计数（点击直达对应筛选）、
磁盘剩余（<30GB 变 warn 色）、主题切换。不放 logo 大标题。

### 5.2 作业看板 `/`

```
│                                                                        │
│  已导出 12    进行中 3    待处理 5    卡住 1     平均耗时 41m          │  ← 单行指标条
│                                                                        │
├ 进行中 ────────────────────────────────────────────────────────────────┤
│  ● running   gb-544-late-event-versioning        运行中 · 已 34m12s     │
│              ▓▓▓▓▓▓▓▓▓░░░░  attempt 2/3          [查看] [停止]         │

│  ● recorded  gb-547-cdc-merge                   待写 Feedback           │
│              ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░                [继续]                  │
├ 卡住 ──────────────────────────────────────────────────────────────────┤
│  ▲ blocked   gb-549-entresolv    Key 失效：网关返回 401 invalid_token   │
│                                  [检查配置] [查看日志]                  │
├ 待处理 ────────────────────────────────────────────────────────────────┤

└────────────────────────────────────────────────────────────────────────┘
```

规格：

- 指标条为**单行 5 个数**，数字 22px tabular，标签 11px `ink-3`，无分隔竖线的堆叠卡片。
- 分组顺序固定：卡住 → 进行中 → 待处理 → 已完成（折叠）。**卡住永远在最上**，这是操作优先级。
- 行高 56（双行信息），悬停整行 `surface-2`，行内右侧出现两个主操作。
- 进度条 2px，宽度 160，颜色随状态。
- 空状态：「今天还没有开工。先从题源领取一个工程。」+ 一个按钮。

### 5.3 任务详情 `/tasks/:id` —— 核心页面

三栏工作台，左固定 264，右可折叠 320，中间自适应（最小 520）。

左栏（StepRail）：

- 每步 `状态点 + 序号 + 名称 + 右侧细节`，行高 34。
- 当前步：左侧 2px accent 竖条 + 文字 `ink` 加粗；完成：ok 点；未开始：空心点 + `ink-3`。
- 底部固定「下一步」区块：一句话动作 + 主按钮。**每屏只有一个主按钮。**

右栏（Inspector，证据卡）：

- 只列**可核验事实**，一律 `label 值` 两列，值用 mono。
- 每项右侧有 14px 复制图标，悬停出现。
- 底部两个动作：打开目录、复制绝对路径。

中栏（Tabs）：

| Tab | 内容 |
|---|---|
| 概览 | 需求逐条勾选表 + 关键结论 + 备注；只读，从 feedback/verification 派生 |
| 题面 | CodeMirror 编辑器 + 右侧字数仪表 + 「安装题面」按钮 + 门禁错误列表 |
| 轨迹 | 虚拟滚动时间线；每步可展开工具输入/输出；顶部搜索与「只看失败」 |
| 产物 | 文件列表（增/删/改 + 行数）+ 点击看 diff；顶部 diff 总量 |
| 录屏 | 录屏计划表单 + 窗口选择器 + 录制控制 + 证据校验结果 |
| Feedback | 编辑器 + 四项仪表 + 检查结果 + 复核确认勾选 |
| 导出 | 11 项检查清单 + 生成/预览 xlsx + 打开 |

Tabs 常驻不隐藏 —— 隐藏 tab 会让人忘记还有步骤。

### 5.4 题源 `/source`

两段式：先选项目，再选工程。

```
┌ 项目 ────────────────────────────────────────────────────────────────┐
│ [下拉：2611-数据工程-第3批 ▾]   active · 11/10–12/15 · 工程 48 · 已领 12 │
└──────────────────────────────────────────────────────────────────────┘

┌ 工程 ────────────────────────────────────────────────────────────────┐
│ [搜索名称]  [语言 ▾]  [文件数 20–400]  [标签 ▾]        ☐ 只看未领取   │
│                                                                       │
│ 名称                       语言    文件  标签            领取          │
│ ───────────────────────────────────────────────────────────────────── │
│ syncmesh-incremental       Python  312   数据工程/其他   [领取]        │
│ qualiscope-profiling       Python  287   数据工程/其他   [领取]        │
│ logmine-template           Go      156   数据工程/其他   ● 我 (10m)    │
└───────────────────────────────────────────────────────────────────────┘
```

- **未选项目时整个工程区为空**，只显示「请先选择项目」。这是 FR-SRC-02 的界面表达。
- 领取按钮点击 → Modal：「领取后你在本项目中独占该工程，其他人不可见；超时会被管理员回收。
  领取后请尽快建题。」+ 确认。
- 已领取行整行 `surface-3` 底，右侧显示「我 · 10 分钟前」+ `[继续建题] [归还]`。

### 5.5 导出 `/export`

- 左：日期选择 + 项目筛选 + 「生成」。
- 右：结果表 —— 行号、任务名、SessionID 前 8 位、分数、字数、状态（✅/⏭ 跳过原因）。
- 底部：跳过原因分组统计（缺录屏 2、缺 Feedback 1、SessionID 重复 1）。
- 生成后出现「打开文件 / 复制路径 / 再次导出」。

### 5.6 设置 `/system`

分组式表单，每组一张无阴影白卡 + 1px 边框：

| 组 | 字段 |
|---|---|
| 技能 | 脚本路径（默认探测）、版本（只读）、`config test` 按钮 |
| 题源 | Base URL、认证方式、用户名、密码（Keychain）、连接测试 |
| 执行 | 容器并发上限、单次超时、尝试次数、任务目录 |
| 录屏 | 允许的应用、最大时长、独立 Chrome 路径 |
| 存储 | 磁盘阈值、清理策略预览 |
| 日志 | 最近 200 条事件 + 下载完整日志 |

## 6. 组件状态规范

每个可交互元素必须有 5 态定义：`default / hover / focus-visible / active / disabled`。
`focus-visible` 统一 `outline: 2px solid var(--accent); outline-offset: 1px`，**不允许 `outline: none`**。

异步内容的三态：

| 状态 | 表现 |
|---|---|
| 加载 | 该区域 12px 高灰条 × 3 行（静态，不做 shimmer 动画） |
| 空 | EmptyState 组件，一句话 + 一个动作 |
| 错误 | `danger-bg` 底 + 原始错误文本（mono）+ 「重试」+「查看日志」 |

**错误必须展示原文。** 网关 401、`docker` 报错、技能 stderr 都要能看到，不做「操作失败，请重试」这种废话。

## 7. 可访问性

- 所有交互元素可 Tab 到达，顺序与视觉顺序一致。
- 状态不能只靠颜色：`● 运行中` 有文字；表格状态列有文字。
- 对比度：正文 `ink` on `paper` ≈ 15:1；`ink-3` on `paper` ≈ 4.8:1（仅用于 12px 以上说明文字）。
- 支持 200% 缩放不横向滚动（表格允许横向滚动但页面不允许）。
- 尊重 `prefers-reduced-motion`（见 `06`）。
