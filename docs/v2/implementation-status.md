## 关键行为

- 平台仍不生成、润色、改写、补全 Feedback，也不自动生成 1–5 分。
- 自动确认记录固定为 `ackedBy=autopilot`；人工抽检结论单独存放在 `audits/` 和 `audits` 表。
- 抽检页只读。打回“重写 Feedback”时只撤销平台自己的确认记录，先回到 `delivering` 由 Agent 重写，再重新检查、确认、导出和抽检。
- 提交批次只收拢 xlsx、录屏等文件，不改写表内绝对路径；这是 Q-V2-3 确认前的安全实现。
- 当前已安装技能版本为 `0.2.3`，`record auto` 已具备 Web 计划执行能力。技能没有 `feedback --reset`；平台不伪造该能力，重写路径按 Q-V2-2 的建议执行。
- 自动交付总开关关闭后不启动自动交付循环，手动门禁与证据流程保持 v1 行为。
- 生产计划的在手上限同时受「目标剩余数」约束：目标 1 时最多只有 1 题在流程中，不会按默认并发额外领取。
